# StudioSpend in Claude

Ask Claude what you have left, what's about to expire, and where to make something, and get an answer from **your own numbers**. Available in StudioSpend **0.3.0 and later**, in Claude Desktop (Mac) and Claude Code.

## Add it

1. In StudioSpend, open **Settings → Claude** and click **Add to Claude**.
2. Claude opens an install window for StudioSpend. Click **Install**.
3. Start a new chat and ask: *"Where should I make a 5-second video?"*

**Using Claude Code?** Under *Using Claude Code instead?* in the same card, copy the one-line command and run it in a terminal where `claude` works.

## What you can ask

- "What have I got left on my video platforms?"
- "Which credits are about to expire?"
- "Where's the cheapest place to make a 1080p video?"
- "How much am I spending a month, and is any plan the wrong size?"
- "Which of my platforms offers Kling 3.0, and where's it cheapest?"

**Where you see the designed card.** In a regular Claude Desktop chat, StudioSpend's answers appear as a card in the chat (what's left, where to make it, what's about to expire). Where Claude doesn't draw cards yet, it shows the same answer as text. In the terminal, Claude Code can only show text.

Claude then generates through that platform's own Claude connector, if you've added it. StudioSpend only advises: **it can't generate, spend or change anything.**

## Privacy

It runs on your Mac and reads the same data the app shows. Nothing is sent anywhere by it, it can't see your platform passwords, and it only answers while the StudioSpend app has recent readings (each answer says how old they are).

## If it doesn't work

| What Claude says | What to do |
|---|---|
| "StudioSpend is not installed" or "can't find it" | Open the StudioSpend app once, then restart Claude. |
| "needs 0.3.0 or newer" | Update StudioSpend, then restart Claude. |
| Nothing changes after fixing it | In Claude, open **Settings → Extensions → StudioSpend**, switch it off and on, and start a new chat. |
| Numbers look old | Open StudioSpend so it refreshes your balances. |

**ChatGPT and claude.ai on the web:** not supported yet. They can only connect to servers on the internet, and StudioSpend keeps your data on your Mac.

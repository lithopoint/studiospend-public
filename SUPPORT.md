# Getting help

| I want to | Do this |
|---|---|
| Report a bug, ask a question or suggest something | In the app: **Settings → Help & feedback**. It opens a short form that reaches us directly. |
| Ask about billing or my license | The same form (choose the billing option), or email **support@studiospend.com**. |
| Ask for my AI platform to be added to StudioSpend | In the app: **Settings → Help & feedback → I run an AI platform**. On the form, choose **I run an AI platform and want it added to StudioSpend**. It asks for your company, a work email and a link to your API docs or MCP server. |
| Read the answers to common questions | [FAQ](docs/faq.md) |
| Report a security problem | Privately. See [SECURITY.md](SECURITY.md). |
| See what changed | [CHANGELOG.md](CHANGELOG.md) |
| Remove StudioSpend | [docs/uninstall.md](docs/uninstall.md) |
| Fix "macOS can't verify StudioSpend" | Re-download from the [releases page](https://github.com/lithopoint/studiospend-public/releases/latest) and check it with [docs/verify.md](docs/verify.md). |
| Fix "Claude can't find StudioSpend" | Open the StudioSpend app once, then restart Claude. Needs version 0.3.0 or newer. |

It helps to include your macOS or Windows version, the StudioSpend version and build (bottom of Settings), and what you expected to happen.

We read everything. We are a small team, so replies can take a few business days.
